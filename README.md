# cue-coach

Legal and support pages for the **Cue Coach** iOS app, served by GitHub
Pages at https://zachlaudev.github.io/cue-coach/

- `privacy/`: Privacy Policy (linked from the app's paywall)
- `terms/`: Terms of Use (linked from the app's paywall)
- `support/`: Support (use as the App Store support URL)

Deploy: Settings → Pages → Deploy from a branch → `main` / root.
